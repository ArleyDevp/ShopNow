# proyecto_final_app

ShopNow is a Flutter shopping app.

The app runs without Supabase configuration. To enable Supabase, pass its URL
and publishable key as compile-time values:

```shell
flutter run --dart-define=SUPABASE_URL=https://your-project.supabase.co --dart-define=SUPABASE_ANON_KEY=your-publishable-key
```
